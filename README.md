# ML Zoomcamp

My learning repository for the [DataTalksClub Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp).

## About

This repository contains my learning materials, Jupyter notebooks, homework solutions, and practical exercises from the Machine Learning Zoomcamp.

The main goal is to develop a strong foundation in machine learning through hands-on practice and understand how to build, evaluate, and deploy machine learning models.

## Course Topics

- Introduction to Machine Learning
- Machine Learning for Regression
- Machine Learning for Classification
- Evaluation Metrics for Classification
- Deploying Machine Learning Models
- Decision Trees and Ensemble Learning
- Neural Networks and Deep Learning
- Serverless Deep Learning
- Kubernetes and TensorFlow Serving

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- FastAPI
- Docker
- Git and GitHub


## Learning Objectives

- Understand the fundamentals of machine learning.
- Develop practical skills in data analysis and preprocessing.
- Implement regression and classification models.
- Evaluate and improve machine learning models.
- Learn model deployment and serving.
- Gain hands-on experience through notebooks and homework.
- Build a foundation for developing end-to-end machine learning projects.
